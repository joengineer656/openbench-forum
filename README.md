# OpenBench forum

Demo homepage designs for OpenBench, an Arabic forum for engineers and makers.

`demo-theme/` holds 10 static homepage demos (11 to 20), each in dark and light mode. They use placeholder content from `demo-theme/shared/data.js`; they are design previews, not the real forum.

Live demos: https://joengineer656.github.io/openbench-forum/demo-theme/
